<h2><a href="https://www.geeksforgeeks.org/problems/find-the-largest-number4953/1">Largest Smaller with Sorted Digits</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given an integer <strong>n</strong> find the largest number which is smaller or equal to it and has its digits in non-decreasing order.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>n = 200
<strong>Output: </strong>199
<strong>Explanation: </strong>200 does not have digits in non-decreasing order since 2 &gt; 0. The largest number less than or equal to 200 whose digits are in non-decreasing order is 199.
</span></pre>
<pre><span style="font-size: 18px;"><strong style="font-size: 18px;">Input: </strong><span style="font-size: 18px;">n = 139
</span><strong style="font-size: 18px;">Output: </strong><span style="font-size: 18px;">139
</span><strong style="font-size: 18px;">Explanation: </strong><span style="font-size: 18px;">The digits of 139 are already in non-decreasing order (1 ≤ 3 ≤ 9), so the answer is 139 itself.</span>
</span></pre>
<p><span style="font-size: 18px;"><strong>Constraints:</strong><br>1 ≤ n ≤ 10<sup>5</sup></span></p></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Mathematical</code>&nbsp;<code>Algorithms</code>&nbsp;
